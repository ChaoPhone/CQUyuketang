# 验证清单

脚本的适配依据是 CQU 自己下发的 HTML / CSS / JS 与公开路由表，**不是登录后的真实 DOM 快照**。
下列各项需要用一个真实 CQU 账号逐条确认。每项都写了「怎么验」和「失败怎么办」。

---

## A. 基础可用性

### A0. 面板不出现 —— 先做这三步排查

**这是最常遇到的问题，按顺序排查：**

**① 确认脚本真的运行了。**
按 F12 打开控制台，刷新页面，看有没有这一行：

```
[CQU雨课堂] 脚本已执行 v1.1.0
```

- **有这行，但没面板** → 脚本跑了，是挂载或页面结构问题，看 A1；
- **完全没有这行** → 脚本根本没执行。继续往下看 ② ③。

**② 检查是不是卡在 `@require` 上（v1.0.0 的坑，v1.0.1 已修）。**
v1.0.0 的元数据块里有：

```
// @require https://cdnjs.cloudflare.com/ajax/libs/html2canvas/1.4.1/html2canvas.min.js
// @require https://unpkg.com/tesseract.js@v2.1.0/dist/tesseract.min.js
```

油猴的规则是**把 `@require` 全部下载完才执行脚本**。`cdnjs.cloudflare.com` 和 `unpkg.com`
在国内网络下经常连接超时，结果就是**脚本一行都没跑、面板不出现、控制台连报错都没有**。

v1.0.1 已删除这两个 `@require`，改成用到时（AI 识图答题）才按需懒加载，带国内 CDN 回退。

**如果你装的是 v1.0.0，必须更新脚本**：油猴面板 → 打开本脚本 → 全选删除 → 重新拖入新文件。

**③ 确认油猴里脚本是启用状态，且 URL 匹配。**
`@match` 只写了 `*://courses.cqu.edu.cn/*`。若学校用的是别的子域，需要在油猴里手动添加。

### A1. 面板是否出现

- **怎么验**：登录 https://courses.cqu.edu.cn/ ，打开 `https://courses.cqu.edu.cn/ai-workspace/lms-graph/31317597/video/84703555?fromProIframe=1&isyth=1&is_chapter=1&node_id=16380147`
- **期望**：左上角出现 `CQU 雨课堂助手` 面板，日志里有 `雨课堂助手 v1.1.0 已就绪` 和路线识别结果
- **失败怎么办**：
  - 控制台显示 `当前在 iframe 内，按设计跳过注入` → 该地址是被父页面 iframe 嵌入的，
    需要在**父页面**（目录页）操作。判断方法：控制台执行 `window.top === window.self`，
    `false` 表示确实在 iframe 内。
  - 控制台显示 `面板挂载失败` → 页面上会出现一个红色提示框，把里面的错误信息发出来。
  - 确认脚本已启用、`@match` 覆盖当前域名。

### A2. 诊断能否正常输出

- **怎么验**：点面板 `🔍 诊断`
- **期望**：控制台出现带 `[CQU雨课堂] 诊断报告` 标题的分组，内含 `路由` / `媒体` / 契约表格 / 目录列表；
  面板日志提示「已复制到剪贴板」
- **失败怎么办**：把控制台报错原文保留。

## B. 第一个测试用例（AI 学习空间视频页）

> 地址：`/ai-workspace/lms-graph/31317597/video/84703555?fromProIframe=1&isyth=1&is_chapter=1&node_id=16380147`

### B1. 路由解析是否正确

- **怎么验**：点 `🔍 诊断`，看 `路由` 对象
- **期望**：
  ```
  kind: "ai", classroomId: "31317597", type: "video", leafId: "84703555",
  nodeId: "16380147", fromProIframe: true, isChapter: true, isCatalog: false
  ```
- **说明**：这一项已离线验证通过（3 段路径 + query 解析），页面上的作用是确认没有额外重定向改写 URL。
- **失败怎么办**：若 `classroomId` / `leafId` 为空，说明站点在跳转后改写了 URL，把实际 URL 记下来。

### B2. **媒体元素能否找到**（最关键的一项）

- **怎么验**：点 `🔍 诊断`，看 `媒体` 字段
- **期望**：`命中根` 为 `document` / `shadow` / `iframe` 三者之一，`类型` 为 `video`，`状态` 里有正常的 `duration`
- **失败怎么办**（`命中根` 显示 `(未找到)`）：
  1. 在控制台手动执行 `document.querySelector('video')`，看是否为 `null`；
  2. 再执行 `document.querySelectorAll('iframe').length`，看有几个 iframe；
  3. 若视频在一个跨域 iframe 里，`Media.find()` 无法穿透（浏览器同源策略，无解），
     需要改为在 iframe 内部单独注入脚本；
  4. 把 `可穿透根数量` 和上面的结果一起反馈。

### B3. 一键启动后是否自动播放

- **怎么验**：点 `▶ 开始刷课`
- **期望**：
  - 日志依次出现：`已找到 video 元素（位置：...）` → `已开始播放：2x，静音，后台挂机中` → `播放已确认推进，开始挂机等待完成`
  - 视频实际开始走时间轴，且**没有声音**
- **失败怎么办**：
  - 日志停在 `正在查找播放器...` → 回到 B2；
  - 日志出现 `浏览器拦截了自动播放` → 点一下页面任意位置即可（一次性）；
  - 日志出现 `媒体未开始推进` → 播放器可能要求先点播放按钮，或资源加载失败（看 Network 面板）。

### B4. 后台挂机是否被暂停

- **怎么验**：视频开始播放后，**切到别的标签页 / 最小化窗口**，放置 2-3 分钟，回来看 `currentTime` 是否持续增长
- **期望**：时间轴持续前进，没有被暂停；没有弹出挂机/切屏警告
- **失败怎么办**：
  - 若被暂停 → 记录当时的弹窗文案（截图），需要补充 `Utils.dismissPopups()` 的匹配关键词；
  - 若弹窗出现但没被关掉 → 同上；
  - 若视频变成静音但暂停 → `observePause` 的 5s 定时兜底应该恢复它，检查控制台有无 `自动播放失败` 警告。

### B5. 倍速是否生效

- **怎么验**：播放中在控制台执行 `document.querySelector('video').playbackRate`
- **期望**：`2`（可在 `⚙ AI配置` 里改成 1~4 之间的值）
- **说明**：若 CQU 的播放器是 `xt-*` 自定义元素，`Player.applySpeed()` 会先驱动它的 UI 再兜底直接设 `playbackRate`；
  两者都失败会每 5s 重试一次。
- **失败怎么办**：若被站点强行改回 1，记录下播放器控件类名（在元素面板里查倍速按钮）。

### B6. 播完是否被正确识别

- **怎么验**：让视频自然播完（或找一个短视频）
- **期望**：日志出现 `播放完成 🎉`；若页面上有进度显示，进度应为 100%
- **说明**：完成判定走双通道（`ended` 事件 / 进度文本），任一满足即算完成。
- **失败怎么办**：
  - 出现 `等待播放完成超时` → 记录诊断里的 `进度锚点` 文本，可能站点用的进度文案不在识别范围内
    （当前识别：`100%` / `98%` / `99%` / `已完成` / `已读` / `已学完` / `已观看` / `n/n`）。

### B7. 播完后的收尾行为

- **怎么验**：观察播完后的跳转
- **期望**：
  - 页面在 iframe 内 → 日志 `本页在 iframe 内，已播放完毕，通知父窗口`
  - 页面非内嵌且有「下一节」→ 日志 `已进入下一节`
  - 非内嵌且无「下一节」→ 日志 `返回目录页继续` 并跳回 `/ai-workspace/lms-graph/<classroomId>`
- **失败怎么办**：把实际行为和控制台日志反馈。

## C. 目录页批量刷课（尚未有真实用例）

以下功能**完全没有真实测试用例**，本次只适配了 B 段的单页播放。

### C1. 专业版目录页 `/pro/lms/:sign/:classroom_id`

- **怎么验**：进入该页，点 `🔍 诊断`，看 `目录` 字段
- **期望**：`目录.total` 大于 0，`items` 里能看到课程标题与类型
- **失败怎么办**（`total: 0`，即 `leafList` 契约全部未命中）：
  在控制台执行下面这段，把结果贴出来即可定位：
  ```js
  [...document.querySelectorAll('[class*="leaf"]')].slice(0, 20)
    .map(e => e.className).filter((v, i, a) => a.indexOf(v) === i)
  ```
  同时试：
  ```js
  [...document.querySelectorAll('[class*="activity"], [class*="catalog"], [class*="chapter"]')]
    .slice(0, 20).map(e => e.className)
  ```

### C2. 叶子类型图标

- **怎么验**：诊断输出的 `目录.items[].icon` 字段
- **期望**：形如 `#icon-shipin` / `#icon-tuwen` / `#icon-zuoye`
- **失败怎么办**：若 `icon` 为空，类型会退化到文本匹配（看标题里的关键词）。
  在控制台执行下面这段确认图标怎么存的：
  ```js
  [...document.querySelectorAll('use')].slice(0, 10)
    .map(u => ({ href: u.getAttribute('xlink:href') || u.getAttribute('href'), cls: u.parentElement?.className }))
  ```

### C3. 完成度状态

- **怎么验**：诊断输出里 `目录.items[].status`
- **期望**：`已完成` / `100%` / `3/12` 这类文本
- **失败怎么办**：若为空，需要把实际显示进度的元素类名补进 `DOM.leafStatus`。

### C4. 「下一节」按钮

- **怎么验**：在学习页执行 `document.querySelector('.btn-next')`
- **期望**：非 `null`
- **失败怎么办**：若为 `null`，在控制台找一下实际按钮：
  ```js
  [...document.querySelectorAll('button, a')]
    .filter(b => /下一|next/i.test(b.innerText || b.className)).slice(0, 10)
    .map(b => ({ text: b.innerText, cls: b.className }))
  ```

### C5. 旧版路线 `/v2/web/studentLog/:classroom_id`

需要确认 `logs-list` 与 `content-box` 类名是否仍存在（首屏 CSS 中 `logs-list` 未命中）。

## D. AI 自动答题（默认关闭，需自行开启）

- 需要先在 `⚙ AI配置` 填 API Key；
- OCR 依赖 `@require` 的 `html2canvas` + `tesseract.js`，若 CDN 被墙会在日志里回退到纯文本模式；
- **正确率不保证**，请自行判断是否启用。

## 反馈模板

把以下内容一起贴出来即可快速定位：

1. 出问题的完整 URL（含 query）；
2. `🔍 诊断` 复制出来的 JSON（面板会提示「已复制到剪贴板」）；
3. 面板日志的完整截图或文本；
4. 期望行为 vs 实际行为。
