# v1.1.2 问题修复与回归记录

验证时间：2026-09-16。验证环境：Windows、无头 Microsoft Edge、Playwright。

## 已修复问题

| 范围 | 根因及修复 |
| --- | --- |
| 拖拽 | 宿主 pointermove 未检查拖拽状态，且混用 iframe 和宿主坐标。现在只在有效拖拽期间使用宿主坐标，释放后停止移动。 |
| 最小化与日志 | 面板从负坐标缩小后可能完全不可见，现在重新约束位置；滚轮兜底只作用于日志区域，新增日志前记录是否位于底部。 |
| 启动按钮 | 异常后 running 和 disabled 未复位，现在统一在 finally 恢复。 |
| 倍速与音量 | 倍速定时器捕获旧值，解除静音只恢复 muted 而没有恢复 volume。现在定时器使用最新倍速，解除静音恢复原音量。小数倍速按钮正确格式化。 |
| 完成判定 | 98%/99%、正文或目录中的完成文字、00:00/00:00 会误判。现在严格判断明确的学习进度，排除目录和正文，零时长不算完成。 |
| 超时和停止 | 超时仍跳转、未找到媒体仍当作完成、停止后仍等待用户手势。现在保留未完成页面、清理播放定时器与手势等待；提交和评论前复查停止状态。 |
| 播放器替换 | 更换元素后仍等待旧媒体结束。现在重新绑定 ended，AI 播放流程同步重建反暂停观察者；跨根媒体时长用于计算超时。 |
| SPA 路由 | 原来只有 boot 分发一次，跳转后没有下一轮运行。现在同一课堂内的 URL 变化会重新分发；其他课堂不继承本次运行。 |
| 存储 | 游标未区分课堂，旧版清除操作使用含查询参数的键。现在游标带课堂 ID，清除进度使用与写入相同的 URL 键。 |
| 跳过与诊断 | 禁用的下一节按钮被报告为成功；考试/直播可能被标题中的“视频”覆盖。现在检查禁用状态并优先识别考试/直播；诊断按路由和跨根媒体结果判断必需契约。 |
| 请求与提交范围 | API 请求无超时；提交按钮兜底搜索整个页面。现在请求最多等待 45 秒，提交仅搜索当前题目范围。 |

## 自动化验证

`tests/regression.cjs` 读取并执行真实 userscript，仅注入内部对象访问入口。没有复制生产函数。所有浏览器网络请求均被本地测试拦截，不访问真实课程、不提交作业、不发表评论，也不调用真实 AI API。

运行命令：

```powershell
node tests/regression.cjs
node --check cqu-yuketang.user.js
tsc --noEmit --allowJs --target ES2020 cqu-yuketang.user.js
git diff --check
```

浏览器测试依赖 Playwright 与 Microsoft Edge；脚本优先使用可解析的 `playwright` 包，否则尝试本机 Codex 捆绑包。可通过 `TEST_BROWSER` 指定其他已安装的 Chromium channel。

首轮 15 项测试：修改后全部通过；对修改前 HEAD 执行相同测试，14 项失败，证明问题可复现。最终共 28 项测试，增加了停止、跨根时长、清除进度、损坏配置、考试跳过、诊断、请求超时和批量内部导航等边界。TypeScript 命令用于现有无类型 JS 的编译器检查，不代表已启用完整 checkJs 类型检查。

## 验证边界

以上是本地 DOM 场景验证，不是登录后的雨课堂验收。真实目录选择器、学习记录上报、同源 iframe 的实际页面结构以及旧版课件完整流程仍需按《验证清单》使用真实页面确认。没有真实账号证据时，不宣称站点所有页面均已验证。
