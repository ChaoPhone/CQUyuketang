## 一、为什么能做适配

调研确认：**`courses.cqu.edu.cn` 是雨课堂「专业版」的贴牌部署**，与 `yuketang.cn` 是同一套前端。

| 证据 | 值 |
| --- | --- |
| `meta keywords` | 雨课堂,清华大学,智慧教学,翻转课堂… |
| 静态资源 | `fe-static-yuketang.yuketang.cn/fe/static/pro/1.3.312/fe-proxtassets/` |
| 页面壳 | `<div id="app"></div>`（Vue SPA） |
| CSP | 无 → 油猴注入不受限 |

所以核心逻辑（播放器接管、反暂停、静音、倍速）可以整体复用，改的是三件事：

1. **域名匹配** → 上游只 `@match` 雨课堂和广财慕课域名，CQU 站点完全不触发；
2. **路由识别** → 上游硬编码 `"yuketang.cn/pro/lms"` 这类字符串，本版改为从 URL 结构解析；
3. **DOM 契约** → 上游用超长绝对选择器（如 `#app > div.app_index-wrapper > … > section.title`），
   站点一层 DOM 调整就静默失效。本版改为**候选选择器链 + 文本锚点**，并提供诊断能力。

### 已验证的路由

路径从 CQU 自己下发的应用包中提取（含 671 条路由定义）：

```
/pro/lms/:sign/:classroom_id[/:type/:leaf_id]     专业版课程目录 / 学习页
/v2/web/studentLog/:classroom_id                  旧版目录（兼容）
/ai-workspace/lms-graph/:classroomId/:type/:leafId   AI 学习空间（已在真实页面验证）
```

## 二、安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）
2. 打开 `cqu-yuketang.user.js`，**拖进浏览器窗口** → 油猴弹出安装页 → 点「安装」
3. **确认脚本已放行**：点浏览器工具栏的油猴图标 → 找到 `courses.cqu.edu.cn` 那一行 →
   若显示「已禁用 / 拒绝 / 需要点击」，改成**允许**（这一步没做会完全没有反应）

## 三、使用

登录平台，打开要刷的**视频页面**，左上角会出现面板：

| 按钮 | 作用 |
| --- | --- |
| `▶ 开始刷课` | 一键启动：接管播放、静音、2 倍速、后台挂机 |
| `🔍 诊断` | 复制完整诊断报告（含日志），用于排查问题 |
| `AI配置` | 配置大模型 API、播放倍速、自动答题开关 |
| `清除缓存` | 清除刷课进度与跳转标记 |
| `停止` | 停止并解除静音、刷新页面 |
| `重载` | 刷新并自动恢复刷课 |

启动后可以**切标签页、最小化窗口**，脚本会自己播完。

### 判断是否正常

面板里应依次出现：

```
✅ 已找到 video 元素（位置：document）
✅ 已开始播放：2x，静音，后台挂机中
播放已确认推进，开始挂机等待完成
✅ 播放完成 🎉
```

看到「已开始播放」就说明成功了。

## 四、常见问题

### 面板不出现

**第 1 步：F12 打开控制台，刷新页面，找这行日志**

```
[CQU雨课堂] 脚本已执行 v1.0.3
```

**第 2 步：对号入座**

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 完全没有这行 | 脚本没运行 | ① 油猴里确认脚本**已启用** ② 确认**站点权限已放行**（见第二节第 3 步） |
| 有日志 + `当前在 iframe 内，按设计跳过注入` | 页面被框架嵌入 | 回外层目录页操作 |
| 有日志 + 红色提示框 | 面板挂载失败 | 把红框里的错误发出来 |
| 有日志 + 面板出现 | 正常 | — |

> 排查经验：最常见的原因是**油猴的站点访问权限没放行** —— 此时油猴显示「已启用」，
> 但脚本在该站点完全不注入，控制台连报错都没有。

### 点「开始刷课」没反应

点 `🔍 诊断`，看输出：

- **关键契约未命中** → 页面结构变了，把诊断报告发出来
- **媒体：命中根 = `(未找到)`** → 播放器在**跨域** iframe 内，浏览器同源策略无法穿透
- **显示「浏览器拦截了自动播放」** → 点一下页面任意位置即可开始（只需一次）

### 诊断里的「其余未命中」要不要管

**不用管。** 未命中的契约分两类：

- **关键契约**：`video` / `audio` / `progressWrap` / `leafList` —— 这些没命中才会影响功能
- **可选契约**：`nextButton` / `batchItem` / `v2LogList` / `subjectItem` / `commentText` 等
  都是**特定页面类型专用**的。比如视频播放页上，作业相关的契约本来就该是空的。

诊断会自动区分这两类，只对关键契约报警。

## 五、已知限制

- **未在全部页面类型上验证过。** 已用真实地址验证 AI 学习空间视频页；
  目录页批量刷课尚无真实用例。
- 播放器若在**跨域** iframe 内，无解（浏览器同源策略）。
- 考试（`exam`）、直播/课堂（`live`）不做自动作答，只跳过。
- 作业自动答题依赖 OCR + 大模型，**正确率不保证**，需先在 `AI配置` 填 API Key。
  OCR 依赖按需懒加载（国内 CDN 可能不可达），失败会自动降级为纯文本识别。
